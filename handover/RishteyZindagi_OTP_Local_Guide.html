OTP — Local mein bypass: kyun aur kaise

RishteyZindagi.com · Developer guide · 22 October 2026

1. OTP kya hai aur website mein kahan aata hai?

OTP (One-Time Password) ek 6-digit code hai jo member ke e-mail ya mobile par bheja jaata hai, taaki pakka ho sake ki e-mail/mobile sach mein usi ka hai. Website mein OTP in jagah aata hai:

JagahLocal mein band ho sakta hai?Note
Naya account banana (Signup verification)HaanSetting: "Registration OTP verification"
Naye device / browser se loginHaan (alag setting)Sirf --all ke saath ya admin panel se
Password reset, account recoveryNahiHamesha code chahiye
Admin login / MFA, contact (e-mail/mobile) changeNahiHamesha code chahiye

2. Local mein OTP bypass kyun karte hain?

  1. OTP bhejne ke liye asli vendor chahiye. E-mail ke liye SMTP account (jaise Gmail/Zoho/SES), SMS ke liye Fast2SMS ki paid API key. Developer ke computer par yeh accounts aur keys nahi hote.
  2. Bina vendor ke code kabhi pahunchega hi nahi. Signup form "Email OTP delivery is not configured" dikhayega aur account nahi banega. Phir aap profile, search, interest, chat, payment kuch bhi test nahi kar paoge.
  3. Asli keys local machine par rakhna risky hai. Keys leak ho sakti hain ya galti se git mein chali jaayein, aur testing mein asli logon ko SMS/e-mail bhi ja sakte hain (paise bhi lagte hain).
  4. Isliye sirf local par OTP ko bypass karte hain, taaki developer baaki poori website aaram se chala aur test kar sake.
Production (live website) mein OTP hamesha ON rakhna hai. OTP OFF hone par naye accounts ka e-mail/mobile "unverified" rehta hai, jisse fake accounts ka khatra badhta hai. Live server par real SMTP ya Fast2SMS lagao aur OTP policy ON rakho.

3. Bypass kaise karein — 3 tareeke

Tareeka A — OTP policy OFF (sabse aasaan, roz ke kaam ke liye)

Signup par OTP ka step hi nahi aata, account seedha ban jaata hai.

# project folder mein terminal kholo
npm run dev:otp -- off             # signup OTP band
npm run dev:otp -- off --all       # signup + naye device login OTP dono band
npm run dev:otp -- on              # dono wapas ON

# ya pehli baar setup karte waqt hi:
npm run dev:setup -- --no-otp      # setup + signup OTP band

Yahi kaam admin panel se bhi hota hai:

  1. http://localhost:3000/admin/login par Super Admin se login karo.
  2. Platform Settings (/admin/super/settings) kholo.
  3. Card "Registration OTP verification" ko OFF karo. Ek chhota reason likhna padega (audit log mein save hota hai). Save karo.

Tareeka B — Development mode (OTP screen par dikhta hai)

Jab OTP wala screen aur poora flow test karna ho, lekin e-mail/SMS na bhejna ho.

  1. OTP policy ON rakho.
  2. Super Admin se login karo, phir Platform Settings → One-time passwords → Development mode → ON → Save.
  3. /signup par signup karo. Code wale screen par "Show my verification code" dabao. Code screen par aa jayega, use daal do.

Code sirf server ki memory se padha jaata hai, kahin e-mail, log ya store nahi hota. Yahi box new-device login aur password reset par bhi aata hai. Live site par (NODE_ENV=production) yeh route 404 deta hai, aur development mode production mein on hi nahi hota.

Tareeka C — Asli e-mail OTP local par (delivery test karna ho)

.env mein SMTP bharo aur OTP policy ON rakho:

SMTP_HOST=...        SMTP_PORT=587
SMTP_USER=...        SMTP_PASS=...
EMAIL_FROM="RishteyZindagi <no-reply@your-domain>"

Local test ke liye Mailpit/MailHog (fake mail inbox) bhi laga sakte ho. SMS ke liye FAST2SMS_* variables, steps FAST2SMS_SETUP.md mein. Check: npm run check:providers aur npm run dev:doctor.

5. Zaroori baatein

  • dev:otp aur dev:setup sirf local ke liye hain. NODE_ENV=production par yeh khud refuse kar dete hain.
  • Setting database mein save hoti hai (platform_settings, key otp.policy), server restart ke baad bhi rehti hai. Har badlav audit log mein jaata hai.
  • OTP OFF mein bhi password, account status aur rate limits lagte hain. Sirf code wala step hat-ta hai.
  • OTP OFF mein bane accounts ka e-mail/mobile "unverified" rehta hai.
  • Abhi kya setting hai, dekhne ke liye: npm run dev:doctor (read-only report).
Live par jaane se pehle checklist: SMTP ya Fast2SMS lagao → npm run check:providers → Admin → Platform Settings: "Registration OTP verification" ON, Development mode OFF → ek asli signup karke dekho ki code aata hai.
