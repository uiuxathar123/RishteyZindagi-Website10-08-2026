## What this checklist is NOT

This is a pre-production acceptance gate run entirely inside a sandbox with no real hosting target, no real payment credentials, no real KMS, and no real object storage. No item above should be read as "deployed to production" — every build/test/migration/backup/restore action ran only against this sandbox's local Postgres instance and throwaway scratch databases created and dropped for that sole purpose.
